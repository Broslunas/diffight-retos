# Primer elemento repetido

Dado un arreglo de $N$ enteros, encuentra el primer elemento que aparece por segunda vez al recorrer la secuencia de izquierda a derecha.

Entrada:
- Primera línea: un entero $N$ ($1 \le N \le 2000$).
- Segunda línea: $N$ enteros separados por espacio, $A_1, A_2, \dots, A_N$ ($-10^9 \le A_i \le 10^9$).

Salida:
- El primer número que aparece repetido. Si no hay ningún elemento duplicado, imprime `NONE`.

Ejemplo:
Entrada:
6
2 1 3 5 3 2
Salida:
3
