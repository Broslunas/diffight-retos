# Sándwiches de Vocales

**Fácil** · strings · Desafío generado · Resuelto

Dado un texto compuesto únicamente por letras minúsculas (`a`-`z`), cuenta cuántos "sándwiches de vocales" contiene.

Un sándwich de vocales es una subcadena de longitud 3 donde:
1. El primer y tercer carácter son vocales idénticas (`a`, `e`, `i`, `o`, `u`).
2. El carácter del medio es una consonante (cualquier letra que no sea vocal).

Las apariciones pueden solaparse. Si la cadena tiene menos de 3 caracteres o no contiene ninguno, la respuesta es `0`.
